# Schrankkorpus (first prototype)

An early cabinet carcass made by hand in the interface, before generated boards
and cutters existed: the parts are stretched, so it has no holes.

- Attributes (German names): width, height, depth, `Staerke`, `Boeden`,
  `Rueckwand`, `Rueckdicke`.
- Parts: two sides, bottom, top, back panel and shelves (`Copies`).

| File | What it is |
|---|---|
| `Cabinet.igz` | The prototype. |

Kept as an example of a component made entirely by hand. The System 32 cabinet in
`../system32-cabinet/` supersedes it.
